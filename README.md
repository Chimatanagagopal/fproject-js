# Game Project

JavaScript Game Portal – Mini Game Interface

Overview  
This project is a small JavaScript-based game portal that allows users to view and access multiple mini-games through a single webpage. It is designed using HTML, CSS, and JavaScript and provides a simple UI for selecting and playing games.

Live Demo  
Visit the live portal:  
https://chimatanagagopal.github.io/fproject-js/project%20js/auth/Games/games.html

Project Explanation  
The main objective of this project is to provide a simple and interactive interface where users can browse and launch mini-games. Each game is represented as a card with a title, image, and a "Play" button.

When a user clicks "Play", they are redirected to a specific HTML file where the game runs. These games are built using HTML canvas and JavaScript logic.

Games included in this portal:
- Snake Game  
- Shooting Game  
- Word Typing Game  
- Click and Score Game  

The interface is styled using CSS and laid out using Flexbox. JavaScript is used to control redirection and interaction. The project structure is organized so that each game can be developed or maintained independently.

Features  
- Clean and responsive card-based layout  
- Game launching with a single click  
- Modular design for adding or removing games  
- Simple and beginner-friendly codebase  

Technologies Used  
- HTML5  
- CSS3  
- JavaScript  
- GitHub Pages for hosting

How to Run the Project Locally  
1. Clone the repository  
   git clone https://github.com/yourusername/fproject-js.git

2. Open the project folder  
   cd fproject-js/project js/auth/Games/

3. Open games.html in your browser  
   You can now click "Play" on any game card to launch the respective game

Deployment  
This project is deployed using GitHub Pages and can be shared with a live link.  
To deploy your own version, push to GitHub and enable Pages in the repo settings.
